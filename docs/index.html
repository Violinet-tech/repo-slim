repo-slim

Keep a git repo from bloating

Stops build output from being committed alongside real source, which quietly grows .git into the hundreds of megabytes. Adds the generated paths to .gitignore, untracks them, and checks that no hand-written file was caught in the same sweep. An optional second pass purges old bulky files from history with git-filter-repo, but it rewrites every commit hash and force-pushes, so it is off by default and always asks first.

Use when: a push warns about a large file, a repo's .git folder is unexpectedly huge, or every commit keeps re-adding the same build artifacts.

Install

git clone https://github.com/Violinet-tech/repo-slim ~/.claude/skills/repo-slim

Works in Claude Code and any harness that reads the SKILL.md format. The markdown is also plain docs, readable without an agent.
